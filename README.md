## What is ZJHCMD?

ZJHCMD is a command-line shell for Windows that goes far beyond `cmd.exe`. It combines:

- **AI-powered command generation** — describe what you want, get a runnable command
- **A symbolic math engine** — expand and factor polynomials, solve equations
- **Deep Windows API integration** — control volume, wallpaper, clipboard, notifications
- **A built-in PE analyzer** — inspect executables without Visual Studio
- **A sandboxed scripting system** — extend it with `.zjhcmd` files

It is a **productivity tool** designed to make Windows command-line work faster, safer, and more approachable.
